# Phase 0.1 — Project Foundation & Architecture

You are a senior Python software engineer and software architect.

Your task is to build the foundation for a production-ready Telegram Outline VPN Platform.

IMPORTANT:
This is NOT a simple Telegram bot.
This is a scalable commercial VPN platform.

Do NOT implement business features yet.
Only create the project foundation and architecture.

SQLite (development)

Modular
