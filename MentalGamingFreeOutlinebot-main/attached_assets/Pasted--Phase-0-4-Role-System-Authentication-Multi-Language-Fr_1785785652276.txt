# Phase 0.4 — Role System, Authentication & Multi-Language Framework

Continue from Phase 0.3.

Only extend the current architecture.

====================================================
GOAL
====================================================

Build the authentication, role management and multilingual framework.

Do NOT implement customer or admin features yet.

Only prepare the architecture.

====================================================
USER AUTHENTICATION
====================================================

Prepare user authentication architecture.

Every Telegram user should have a profile.

Store:

Telegram ID

Username

First Name

Last Name

Language

Role

Status

Created At

Last Active

Future fields should be easy to add.

====================================================

Supported roles:

Admin

Customer

Reseller

Affiliate

Moderator

VIP

Roles should be database driven.

Never hardcode permissions.

====================================================

Never ask again unless changed.
