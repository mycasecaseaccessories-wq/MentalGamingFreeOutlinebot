# Phase 0.2 — Database Architecture & Repository Layer

Continue from Phase 0.1.

Do NOT rewrite the existing project.

Only extend the current architecture.

====================================================
GOAL
====================================================

Build a scalable database architecture for the Mental Outline VPN Platform.

Do NOT implement business features yet.

Only prepare the database layer.

The architecture must support SQLite now and PostgreSQL later without major code changes.

====================================================
DATABASE LAYER
====================================================

Create a centralized database module.

Requirements:

• Single database connection manager
• Async compatible
• Easy migration to PostgreSQL
• Repository pattern
• Transaction support

====================================================
DATABASE STRUCTURE
====================================================

Prepare folders:

database/

database/models/

database/repositories/

database/migrations/

database/session.py

database/base.py

====================================================
BASE MODEL
====================================================

Create a reusable BaseModel.

Include common fields:

id

created_at

updated_at

All future tables must inherit from BaseModel.

====================================================
REPOSITORY PATTERN
====================================================

Prepare repositories.

Example:

ServerRepository

VPNKeyRepository

WalletRepository

OrderRepository

GrowthRepository

SettingsRepository

NotificationRepository

Only create repository structure.

Do NOT implement business logic.
